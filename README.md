# KalipheTiles (Windows 11)

Géoréférencement d'images (JPG/PNG), tuiles XYZ / MBTiles / GeoPackage, GeoTIFF, Shapefile, GeoJSON, KMZ, world files, envoi S3.
Résultats dans `Documents\KalipheTiles\<id>\` (exports dans `exports\`). Projets : `Documents\KalipheTiles\*.ktproj`.

Fenêtres flottantes : déplacer par la barre de titre, redimensionner au coin bas-droit, « – » pour réduire.
Raccourcis : Ctrl+Z / Ctrl+Y, Suppr, Échap, Ctrl+S.

## Compiler le .exe
Poussez ce dossier sur GitHub : l'onglet Actions produit l'artefact KalipheTiles-windows.
